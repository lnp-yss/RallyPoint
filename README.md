# Rally Point

Pickleball scoreboard and club management software for Raspberry Pi.

The application source, tests, installation scripts, and deployment documentation
are in [`opt/rallypoint/app`](opt/rallypoint/app).

- [Application README](opt/rallypoint/app/README.md)
- [V3 club and web setup](opt/rallypoint/app/README-V3.md)
- [Raspberry Pi deployment](opt/rallypoint/app/DEPLOYMENT-PI.md)

The Bluetooth broker is in [`usr/local/lib/rallypoint`](usr/local/lib/rallypoint).
This repository preserves the supplied deployment directory layout.
